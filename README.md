This repo contains code used to generate analysis and figures for "The impact of 
immune imprinting on spatial risks for a future influenza pandemic in the United 
States". Please contact atc10260@uga.edu with any questions or comments.

Code used to generate imprinting probabilities is adapted from "Potent 
protection against H5N1 and H7N9 influenza via childhood hemagglutinin 
imprinting" by Gostic et al., 2016. 

Paper figures are generated in code/results/figs_for_paper.R. Figure PNGs are
within the code/figs folder.
